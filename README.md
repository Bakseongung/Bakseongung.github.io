# 박성웅 | Cloud Infrastructure Engineer Portfolio

클라우드 인프라 엔지니어 박성웅의 포트폴리오 사이트 소스입니다.

🔗 Live: https://Bakseongung.github.io

## 소개

이벤트 드리븐 Kubernetes, 하이브리드 클라우드 DR, IaC를 설계하고
로그와 메트릭으로 증명하는 신입 클라우드 인프라 엔지니어입니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 구조와 콘텐츠 |
| `style.css` | 레이아웃, 다크 모드 지원 |
| `script.js` | 메뉴 강조, Scale-to-Zero 터미널 애니메이션, 연락처 복사 |

빌드 도구 없이 정적 파일만으로 동작하며 GitHub Pages로 배포합니다.

## 로컬에서 확인

```bash
python3 -m http.server 8000
# http://localhost:8000
```
