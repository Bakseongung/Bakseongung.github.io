트러블슈팅

  • 이미지 업로드 실패 문제Backend는 Presigned PUT URL을 정상 발급했지만, 브라우저가 그 URL로 Ceph RGW에 PUT하는 단계에서 업로드 실패 원인URL 생성 시 ContentLength를 지정해 content-length가 서명 조건에 포함됨 해결Presigned PUT URL을 만드는 PutObjectCommand에서 ContentLength 항목 제거 브라우저 업로드 시 발생하던 서명 조건 문제 해결
  • Ceph Pod 생성 실패 문제OSD/RBD 관련 Pod 생성 에러 원인워커 노드 커널에 rbd 모듈이 로드되지 않음 해결커널 모듈을 즉시 로드하고, 재부팅 후에도 자동 로드되도록 영구 설정 Ceph Pod 정상 생성
  • PostgreSQL을 어디에 둘 것인가 문제Ceph 분산 블록 스토리지는 고가용성을 주지만 네트워크 복제 때문에 쓰기 지연이 생기고, 로컬 디스크는 빠르지만 노드 장애 시 DB 가용성을 잃음 원인PostgreSQL은 쓰기 I/O 속도가 중요해 네트워크 지연에 민감하고, 로컬 배치는 노드 다운 시 서비스 전체가 멈출 위험이 있음 해결Ceph 3-Replica 블록 풀을 PostgreSQL 전용 볼륨으로 마운트하고, 클러스터 내부 통신 전용 네트워크 대역을 분리해 복제 지연 최소화 노드 장애에도 데이터 유실 없이 즉시 페일오버, DB 트랜잭션 지연 최소화
  • Tx Unit Hang (처리량 한계 초과) 문제csi-rbdplugin이 304번 실패하며 CrashLoopBackOff 원인VMware의 e1000 가상 랜카드(1Gbps)에서 대용량 트래픽이 발생하면 커널 로그에 Tx Unit Hang 에러 발생 해결.vmx 파일에서 어댑터를 e1000에서 vmxnet3(10Gbps)로 변경하고, 메모리를 6GB에서 8GB로 확장 csi-rbdplugin 장애 빈도 감소
  • Ceph 전환 시 초기 투자비는 언제 회수되는가 문제실제 장비 단가와 운영비는 데모값이고, 실제 전기 실측값은 알 수 없음 원인파라미터를 많이 늘리는 것보다 꼭 필요한 데이터를 고르고 중요도를 추정하는 것이 중요 해결한국에서 실제 거래되는 값들의 평균으로 계산 스케일 NVMe 단가, 서버 CapEx, Ceph 월 전기요금, 연 운영비(직원 고용비 포함), 월 클라우드 비용을 반영한 TCO 의사결정 대시보드로 손익분기 계산 가능
